Este projeto tem como objetivo aplicar os conceitos de estruturas condicionais e funções em C para simular um sistema inteligente de controle de temperatura. Você irá desenvolver um programa capaz de monitorar a variação de temperatura e tomar decisões automáticas conforme faixas de valores predefinidas, representando o comportamento de sistemas embarcados simples utilizados em residências, automóveis e indústrias.
